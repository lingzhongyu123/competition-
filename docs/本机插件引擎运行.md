## 再运行一次

在 Console 目录执行；路径请按本机 checkout 替换：

```sh
npm install --prefix /path/to/dsh-advanced-mem-plugin --omit=dev --legacy-peer-deps --ignore-scripts --package-lock=false --no-audit --no-fund
node --experimental-transform-types scripts/run-local-experience.mjs --plugin-root /path/to/dsh-advanced-mem-plugin --output-dir .local/new-run
```

需要 Node.js 24；所选输出目录必须不存在。上游固定为 f840e1c，版本不符时停止以便重新核查。只安装独立 API 依赖，没有自动安装全局 DSH，也没有调用模型。

打开输出目录中的 `本机插件运行-查看.html` 可直接查看已加载的记录；另有 `experience-snapshot.json` 可在标准网页“经验快照”中手动导入，及 `run-report.json`、原始 CSV、输出 CSV、操作回执和持久化 store。页面仍标为本地导入、来源未由 Console 核验。

运行产物位于忽略目录，不上传本地运行日志或存储。本轮公开提交仅包含可复现脚本、说明及验证记录。
