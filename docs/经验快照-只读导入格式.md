# 经验快照：只读导入说明

2026-10-26。入口：左侧“经验快照”，HTTP 路由 #import。字段对应 Memory 插件 0.3.0 的 [ExperienceSnapshot 类型](https://github.com/CenYangtze/dsh-advanced-mem-plugin/blob/f840e1cdd5372cf74c7f7a6bce2e797c2f2b401a/src/experience/types.ts)及同版本 schema.ts。它是离线查看入口，尚未连接 DSH，也不是在线 Memory API。

## 如何使用

1. 选择 snapshot(scope) 导出的 JSON 文件，或展开“或粘贴 JSON”。只接受一个完整的快照对象，不接受命令输出文本、事实 store、OSWorld trajectory 或结果报告。
2. 查看经验策略、来源任务、版本记录、反馈记录；可以搜索标题/任务/理由/ID，每页 25 条。点击策略的来源任务或版本记录可跳转到对应详情。
3. 文件中的状态与结果按原值显示。success / verified 是文件声明，不代表 Console 验证过环境或证据；recalledSkills 不等于注入或采用；置信度不是成功率。
4. 原始引用未包含在快照时显示“来源缺失”或“未记录”，不会生成代替记录。失败导入会清空旧数据并显示原因，不自动回退为 MOCK。
5. 文件内容只保留在当前页面内存中；切换导航可继续查看，刷新、清空本页数据或全局重置会移除。代码不上传文件、不写入 localStorage/IndexedDB、不修改插件数据库。

“查看 MOCK 字段示例”是单独的显式入口，生成自建候选及 unknown 结果。无论导入文件自称什么来源，文件导入均标记“本地导入 · 来源未核验”；只有内置示例按钮使用 MOCK 模式。所有本轮测试数据都是合成数据。

## 数据取得方式

由拥有已初始化宿主上下文和相应作用域权限的协作者，在服务端调用 ctx.experience.memory.snapshot(scope)，序列化返回对象。该方法不是独立网页可直接访问的 HTTP 地址。本轮不提供猜测的 URL，也没有运行上游服务。

导出前由数据提供方选择可分享的作用域并脱敏；替换 ID 时应同步更新引用。时间戳是毫秒整数，页面以 UTC ISO 显示。建议先给一个小作用域。不要把私人运行样例提交到本仓库；当前页面不需要任何 API 密钥。

最小空快照（仅说明容器，不代表真实数据）：

~~~json
{"schemaVersion":1,"scope":"example-empty","episodes":[],"skills":[],"revisions":[],"feedback":[]}
~~~

## 显示映射

| 上游字段 | 页面呈现 |
|---|---|
| skills | 标题、类型、文件状态、版本、适用条件、流程、注意事项、验证方法、工具和环境 |
| skills.episodeIds | 来源任务跳转；缺失 ID 明示 |
| episodes | 任务、摘要、会话、时间、动作与观察、执行元数据、原始证据 ID |
| episodes.outcome | 文件声明的结果、来源、理由与评估 criteria 引用原文 |
| episodes.taskContext / derivedFrom | 多轮修订与前驱关系 |
| episodes.recalledSkills | 当时召回的策略 ID/版本；不标成已采用 |
| revisions | 历史版本的内嵌 skill，保留版本号与变更理由 |
| feedback | 反馈声明及独立的动作引用/验证引用；不根据 verdict 推断实际采用 |

## 校验范围与限制

- 最多 5 MiB UTF-8 JSON；每个受校验数组最多 500 项，单文本字段最多 50000 字符；JSON 深度最多 24，遍历节点最多 100000。超限给出失败提示，请拆分作用域或精简导出。
- 必须包含 schemaVersion: 1、非空 scope，以及 episodes/skills/revisions/feedback 四个数组；校验已显示的必需和可选字段类型、枚举、数字范围、任务起止时间。
- 各集合 ID 不得重复；任务/策略作用域必须一致；修订号/策略 ID 必须与内嵌 skill 对应。异常属性名拒绝；展示文本统一转义，既不当 HTML 也不当脚本执行。引用原文空白保留。
- 缺少关联实体、部分 outcome 引用不完整、tool-evidence 缺少 assessment 会提示。其余引用真实性、事件时序、原件一致性、完整验收覆盖、宿主阈值等未全面验证。
- 这是独立实现的展示结构检查，**不等价于上游完整 Zod schema、experienceToolOutcomeIssues 或运行时策略**。未识别字段不会被用来推导结论；不能把“可导入”理解为上游可接受或已经真实执行。
- 当前没有事实记忆文件导入、在线鉴权、真实数据自动刷新、写入、撤回、删除或评测能力。独立快照也不能证明 Memory ON/OFF 收益。
