# LongMemEval 运行档案

打开根目录 `longmemeval-runs.html`，选择含 cases_index.json 与 cases 子目录的完整导出目录。页面在浏览器内存读取文件，不联网、不上传、不持久化；刷新或清空移除数据。网页代码可公开，原始导出包仍只保存在本机忽略目录。

可按案例和轮次并排查看 A/B/C 回答、实际上下文、Reader 请求、Judge 记录及用量与时延。评分详情含参考标签，仅作评测档案查看。来源区可搜索 L0 恢复原文与 L1 冻结节点，展开查看索引文本和 evidence 原始引用。L1 节点下可展开 evidence 对应的 L0 原文，缺失或歧义明确提示；尚未实现图形连线。

该页是独立只读入口，现有首页及 MOCK 演示不变。支持单一 cohort，最大 100 个案例、1000 个文件、总计 100 MiB、单 JSON 12 MiB；不接受重复案例或问答单元。缺失文件和格式不符会提示错误，不回退为 MOCK。内容全部作为文本显示；来源真实性、评分正确性与实验收益未独立核验。

2026-10-29：使用提供的完整导出包在隔离 Edge 验证 7 案例加载、三组卡片、第三轮切换、L1 查看、390px 无横向溢出与清空，页面无脚本异常。未重跑原页面回归、模型或评分。原始数据与本机截图不上传。

运行档案也读取可选的 profile_and_retrieval.json，按组展示召回顺序、信号、来源、画像和上下文构造记录。比较冻结上下文与所选轮次的实际输入。缺少此文件时仍可查看回答与来源，明确提示检索档案未提供。
