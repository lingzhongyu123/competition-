# 项目改动与当前进度

## 2026-10-25：将真实样本接入主控制台

### 修改原因

远端已有 LongMemEval 独立样本导览，但主控制台及部分交接文字还写着“原始样本尚未取得”。两个入口脱节，不便展示“原话如何成为记忆候选、信息怎样更新”。本轮在协作者最新版本上整合入口，保留独立导览与原 MOCK 演示。

### 具体变化

- 主导航增加“真实样本”，复用 4 条公开 oracle 样本、7 个原始会话；事实、偏好、信息更新和时间推理均可浏览。
- 将人工整理的记忆候选和真实英文来源并列展示。原文按钮可展开完整会话、定位并高亮具体消息。
- 更新样本增加两个陈述时点：早期只显示 27:12 与当时来源；后期显示 25:50，同时保留 27:12 的历史陈述。陈述时间不冒充比赛发生时间。
- 标明原始会话已取得、候选由人工整理、检索与执行未采集。公开样本区不显示 MOCK 指标、模拟时间线、模拟详情或模拟导出。
- 修复顶部搜索在导航时清空关键字的问题；同步数据准备状态与交接文档。
- 构建内嵌公开 JSON 与新增样式，同时更新根目录演示；修复 Windows CRLF 导致的打包白屏，写出前校验内联脚本语法。
- 静态服务仅为指定公开文件增加入口。开发/测试最低 Node 版本明确为 20.18.3，以支持 JSON import attributes。
- 将“每次提交前读取远端变动文档、核对进度、详细说明改动”的用户要求写入 AGENTS.md。

### 验证与边界

11 项测试通过，构建与语法检查通过；已验证真实样本关键交互、顶部搜索、桌面/390px 布局和通过 HTTP 独立加载的单文件演示。详细范围及未测项见《验证记录》。没有真实 Memory/DSH 接入、执行轨迹或评测成绩；oracle 不是完整长历史。
