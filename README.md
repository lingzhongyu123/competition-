# 麒麟 Memory Console

基于讨论稿制作的独立交互原型。“真实样本”展示 4 条 LongMemEval oracle 样本、7 个原始会话及人工整理的记忆候选；“任务故事草图”用 3 条 OSWorld 官方任务定义讨论任务经验与复用，并提供显式选择的 MOCK 逐步演示。其余工作区的记忆、时间轴和执行轨迹仍明确标注为 MOCK。已在隔离的 DSH 0.2.1-rc.2 环境中通过伴随插件打开演示页面，但页面尚未接实时 Memory 数据或 OSWorld 评测运行器。

DSH 页面试验及可切换的麒麟风格预览见 [插件说明](plugins/memory-console-dsh/README.md)和 [实际验证记录](docs/DSH-前端接入可行性核查.md)。

首页用报名表讲完整的四章故事。菜单“补充材料”仅保留对话样本（事实与更新）、任务样本（经验与复用）两类展示材料，页面说明其与主线的关系，并可返回对应章节。补充案例与首页为独立数据，不拼接成一次真实经历。来源、字段与接入说明按需展开；经验快照和完整 MOCK 工作台用于补充检查。

## 启动

开发与测试需要 Node.js 20.18.3 或以上（支持 JSON import attributes），无运行依赖，无需 npm install。源模块页面使用现代 Chromium 浏览器；直接打开单文件演示不需要 Node。

```sh
node scripts/serve.mjs
```

将源码解压后，在含 package.json 的仓库目录运行上述命令。默认访问 http://127.0.0.1:4173/ ，服务绑定本机回环地址。设置 PORT 环境变量可调整端口。

## 构建与验证

```sh
node --test tests/*.test.mjs
node scripts/build.mjs
```

构建同时更新 `dist/memory-console.html` 和根目录 `双击打开演示.html`，两份内容一致，样本数据和样式全部内嵌。根目录演示纳入版本控制；dist 和临时截图不纳入。构建兼容 LF/CRLF，并在写出前校验内联脚本语法。npm test / npm run build 仍可使用。

可选浏览器回归（需启动本地服务，且测试环境已提供 Playwright 与 Chromium）：

```sh
node tests/ui.cjs
```

`BROWSER_PATH` 可指定 Chromium 可执行文件，默认 `/usr/bin/chromium`。Playwright 只用于可选浏览器检查，未作为应用依赖安装。截图写入 `artifacts/`。

## 已能演示

- 默认首页围绕“整理活动报名表”连续展示事实记忆、信息更新、任务经验与复用：同一份表依次出现时间排序、规则变更、文本排序错误、数值修正和第二批数据复用。共四章八幕，支持播放、暂停、逐步与章节跳转；来源按需展开，全程标注 MOCK，公开样本保持独立。

- “经验快照”：本地只读导入插件 ExperienceSnapshot v1，查看策略、任务、版本和反馈；文件来源未核验，与内置 MOCK 分开。格式与限制见 [导入说明](docs/经验快照-只读导入格式.md)。

- “真实样本”：中文节译 → 人工记忆候选的图解；英文原句、完整会话及解释按需展开。涵盖事实、偏好、信息更新、时间推理；可定位具体原始消息。
- 信息更新样本支持 5 月 25 日 / 27 日切换；早期视图不显示较新陈述，较新视图保留旧值和原文。
- “原始会话已取得 / 记忆候选人工整理 / 检索与执行未采集”分别显示，避免把人工说明当成系统结果。
- “任务故事草图”可切换工时任务的经验形成、产品收入汇总到发票计数的拟议复用；官方任务、人工候选与待采集证据独立显示。
- “MOCK 逐步演示”：同一工时例子从 08:30 → 8.5 小时 → 金额 340，留下方法，再用到 09:15 的新任务。以换算图和状态链代替长字段表，可选择只有注入、执行采用、产物核验、条件不符四种证据情况；所有过程均为人工预设。官方透视表迁移配对仍在任务资料中，未当作本次工时经历。
- 事实/偏好/约束/案例/策略的搜索、类型与状态筛选。
- Day 01、03、07、10、14 历史快照；未来记录与未来替代时间不可见。
- 记忆详情、原始证据和作用域；图谱区分来源与注入关系。
- 同范围的排序规则更新；不影响日期格式与修改范围。
- 检索候选、选中、实际注入字段和执行引用分别显示。
- 合成成功/失败案例、策略适用条件及反例；不宣称真实运行收益。
- 有范围预览与确认的模拟撤回；历史只读，历史 trace 不会被重写。
- 导出 MOCK JSON 证据包、重置演示、主题切换、窄屏布局。
- 5 条真实 OSWorld Calc 任务定义，其中 1 条 evaluator 标记 infeasible；无运行结果。

刷新或重置会恢复演示数据。主题仅在本次页面会话中切换。“麒麟”是概念视觉，不是官方设计规范。

## 当前限制

已在本机实际运行上游独立经验 API，完成自建 MOCK 输入的 CSV 操作、记录、人工候选提交、召回、显式复用、证据反馈及快照导出。复现方式见 [本机插件引擎运行](docs/本机插件引擎运行.md)。这不涉及模型自动提炼、DSH 挂载或 OSWorld；运行产物留在本地，不纳入仓库。

现有经验快照导入可配合 [只读导出工具与使用说明](docs/CenYangtze-仓库筛选与快照导出.md) 使用：从指定 FileExperienceStore scope 导出，或在已运行的 DSH 宿主里调用导出函数。仍需提供真实存储路径或宿主上下文；仓库不包含私人运行快照。

LongMemEval oracle 的 500 条样本已取得，其中 4 条已接入页面；oracle 仅含证据会话，不代表 S/M 完整长历史。中文字段和摘要属于人工解读，没有真实记忆写入、检索、注入、执行或评分记录。现已取得 Memory 插件 0.3.0 源码及其 DSH 0.2.1-rc.2 兼容说明，找到原生配置页与事实/经验读取的程序接口；团队实际部署版本和 Console 联调仍待确认。上游已有经验引擎实现，本 Console 尚未接入其真实数据，不能把本地模拟案例当作后端执行结果。详见 [源码核查与接入清单](docs/Memory插件-源码核查与接入清单.md)。

模拟工作区使用 mock provider，真实样本使用单独的静态公开数据入口，不提供线上接口失败时回退合成数据的“在线模式”。真实 API 接入时必须单独处理加载、空结果、权限、错误与能力不可用状态。详见交接说明与 docs/改动记录.md。

### 展示动效

首页使用本地固定版本 GSAP 3.15.0 编排指令、连线、规则和历史记录，支持暂停/续播、选步及重播。运行时内嵌在单文件中，离线展示无需 CDN；版权及来源见 [vendor 说明](src/vendor/README.md)。系统减少动态效果时保留步骤状态，关闭位移动画。
